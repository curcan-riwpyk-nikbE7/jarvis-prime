**J.A.R.V.I.S. Prime** — это автономный агент нового поколения с голосовым интерфейсом, созданный для реального управления операционной системой Windows и автоматизированного видеомонтажа. 

В отличие от простых чат-ботов, Джарвис Прайм обладает **руками** (Computer-Use), **медиа-комбайном** (FFmpeg Studio) и **ReAct-логикой** планирования сложных цепочек действий.

---

## 🚀 Ключевые возможности

### 🎬 Автоматический видеомонтаж (Media Engine)
- **Нарезка и склейка:** Срезает фрагменты по таймкодам, объединяет десятки файлов в один ролик.
- **Удаление тишины и пауз:** Автоматически вырезает паузы в речи спикера для создания динамичных Reels / Shorts / YouTube видео.
- **Работа со звуком:** Извлечение аудиодорожек, наложение фоновой музыки с регулировкой громкости.
- **Конвертация и сжатие:** Изменение разрешения (1080p, 4K, 9:16 vertical), оптимизация битрейта.

### 🖱️ Автономия и Computer-Use
- **Контроль рабочего стола:** Управление курсором мыши, клики, ввод текста, горячие клавиши.
- **Управление окнами:** Поиск открытых окон, сворачивание, разворачивание, переключение между софтом (Premiere Pro, Photoshop, DaVinci, Браузер).
- **Системные команды:** Запуск любых приложений, выполнение PowerShell-скриптов.

### 🎙️ Голосовой контур реального времени
- Распознавание русской и английской речи.
- Синтез естественного мужского голоса британского джентльмена.
- Возможность текстового управления в терминале или голосового режима «hands-free».

## 📦 Быстрый старт

### 1. Клонирование репозитория
```bash
git clone https://github.com/ВАШ_НИК/jarvis-prime.git
cd jarvis-prime
```

### 2. Автоматическая установка (Windows)
Запустите файл:
```cmd
setup_env.bat
```
Либо вручную:
```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

> **Важно:** Для функций видеомонтажа на компьютере должен быть установлен **FFmpeg** (утилита скачивается автоматически через скрипт или с `ffmpeg.org` и добавляется в PATH).

### 3. Настройка окружения
Скопируйте конфигурацию:
```cmd
copy .env.example .env
```
Укажите ваш API-ключ Gemini или Groq в `.env`.

### 4. Запуск
```cmd
run.bat
```

## 🛡️ Архитектура проекта
```
jarvis-prime/
├── jarvis/
│   ├── config.py           # Конфигурация и переменные окружения
│   ├── core.py             # ReAct агент, парсинг намерений и вызовы функций
│   ├── voice/              # Модули распознавания и синтеза речи
│   └── tools/              # Инструменты:
│       ├── video_editor.py # Монтаж видео через FFmpeg
│       ├── computer_use.py # Мышь, клавиатура, окна
│       ├── file_manager.py # Работа с файловой системой
│       └── terminal.py     # Исполнение команд Windows
├── run.bat                 # Запуск ассистента
├── setup_env.bat           # Установщик
└── requirements.txt        # Список зависимостей
```
